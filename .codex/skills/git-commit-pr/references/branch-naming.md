# Branch Naming

```
<type>/<issue-number>-<slug>     # GitHub Issue number known
<type>/<slug>                    # no issue number
```

- `type`: `feat`, `fix`, `docs`, `refactor`, `chore`, or `hotfix`
- `issue-number`: bare GitHub Issue number, without `#`
- `slug`: lowercase kebab-case, two to five words, with no issue number

Ask for the GitHub Issue number first. If none exists, derive the slug from the changed files or task; confirm only when the resulting name is non-obvious.
